# 🦠 COVID-19 Dashboard – Power BI Project

## 📊 Project Overview

This project showcases an interactive Power BI dashboard analyzing the impact of COVID-19 in the United Kingdom. The goal was to transform raw public health data into meaningful insights that could help stakeholders understand key trends in infection, mortality, and vaccination rates across time.

---

## 🎯 Objectives

- Track daily and cumulative COVID-19 cases, deaths, and vaccinations
- Identify trends over time using visual analytics
- Break down data by region to highlight geographic disparities
- Provide accessible, real-time insights to inform public understanding

---

## 🧰 Tools & Technologies Used

- **Power BI** – Data modeling, dashboard creation, DAX calculations  
- **Microsoft Excel** – Data cleaning and transformation  
- **Power Query** – ETL (Extract, Transform, Load) process  
- **DAX** – Calculated columns and measures for KPIs  

---

## 🗂️ Data Source

- **UK Government COVID-19 API**: [https://coronavirus.data.gov.uk](https://coronavirus.data.gov.uk)
- Data includes daily and cumulative figures for cases, deaths, and vaccine doses administered, segmented by date and location.

---

## 🔍 Key Features

- 📅 Time-series charts showing trends in cases, deaths, and vaccinations  
- 📍 Regional breakdown with interactive filters (slicer by area)  
- 📈 KPI cards for current totals (daily and cumulative)  
- 📉 Mortality vs. case rate comparison  
- 📊 Clean layout using Power BI themes for clarity and accessibility  

---

## 💡 Insights Gained

- Identified time periods with the highest surge in infections
- Tracked vaccination progress vs. case decline
- Highlighted regional inequalities in health outcomes
- Practiced complex data transformation using Power Query
